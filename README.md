# Sales Forecasting Using Machine Learning

## Project Overview
This project uses Linear Regression to forecast future monthly sales based on sample historical sales data.

## Objectives
- Analyze monthly sales data.
- Train a Linear Regression model.
- Forecast sales for the next three months.
- Visualize actual and predicted sales.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Project Files
- `main.py` — Main Python program.
- `sales_data.csv` — Sample monthly sales dataset.
- `sales_forecast.png` — Generated sales forecast graph.

## How to Run
1. Install Python 3.13 or a compatible Python version.
2. Install the required libraries:

   `python -m pip install pandas matplotlib scikit-learn`

3. Run the program:

   `python main.py`

## Methodology
The program uses monthly sales data from months 1–12 to train a Linear Regression model and predict sales for months 13–15.

## Note
This project uses sample sales data for demonstration. Forecasts are estimates and may not represent real business sales.
